1 · The loop — one dt (dt = 10 ms)

Run-level: two stages share this exact loop — pose (target held at its first frame until both ankle errors settle) and track (mocap trajectory played). Everything below is per dt, every dt — parameter and σ updates included.
PERSONA · site 1 · Sample the site distributions
εs(t) ~ N(0,1)  →  x̂s(t) = clip( μs(t) + σs(t)·εs(t) )  →  Δθs(t) = x̂s(t) − μs(t) = σs(t)·εs(t)
Each site writes (x̂s(t), σs(t)) into its own noise recorder; the sampled distribution is then realized in NEST (per-neuron / per-synapse draws, see §2).
↓
NEST · CPG 2 · Sensory routing Poisson generator rates for CUT / Ia-E / Ia-F / Ib-E / Ib-F (per leg, from the previous physics state) — every rate from MuJoCo, no timers. Rate deltas are written to the Poisson recorders.
↓
NEST · CPG 3 · Simulate dt
spikes → muscle drive   d(t) = clip( nspikes / (N·νref·dt) , 0, 1 )
STDP projections update their weights (plasticity owns them); the per-projection weight deltas are drained into the STDP recorders.

MuJoCo · plant 4 · Physics dt SOL/TA drives → hindlimb dynamics → outputs y(t) = [ankleL, ankleR] and the new sensory state (CUT contact, Ia length+velocity, Ib force) which returns to step 2 next dt — a 1-dt sensory latency, and any parameter change needs several dt to surface in y. This is why credit must reach back.

Single persisted strategy — no separate stance/swing strategy state; only the baseline differs per phase.

strategy 7 · Strategy — two kinds of information, persisted and β-merged
X̄t = β·X̄t−1 + (1−β)·Δθt      Ft = β·Ft−1 + (1−β)·ststT      Gt = β·Gt−1 + (1−β)·X̄t·AtT
Type 1 (F): where to search — metric from the sampled distributions (σ-channels and noise channels included). Type 2 (X̄, G): how previous samples impact the current state — a sample from k steps ago still sits in the trace X̄ when its effect finally surfaces in At, so credit lands in the right place. Nothing is pruned at phase flips; β alone ages everything (see §3).

update 8 · Apply, every dt
gt = Gt·12    Δμt = ημ·(Ft+λI)−1·gt    Δlogσi = ησ·clip( (zi²−1)·Āi )
μ ← clip(μ + Δμ); σ ← clip(σ·exp(Δlogσ)). Computed from sampling-time μ, σ (fixes today's order bug). → next dt.

Noise recorders — by producer (read-only)

PERSONA sites — stream of (x̂, σ) per site. Source of the σ-channel and the sample trace X̄. Every site has its own recorder (unique key).
STDP synapses — per plastic projection (CUT→RGE, Ia→RG): mean weight delta per dt, from the NEST weight recorder.
Poisson generators — per generator: rate delta per dt (sensory CUT/Ia/Ib; BS, BASE).
Noise is never written by the agent. Each recorder keeps a β-decayed distribution of its channel. Noise enters the metric F, is excluded from the trace X̄ (it is not ours to credit), and modulates how long/short the parameter step is through the covariance structure — old STDP/Poisson fluctuations keep influencing the strategy, just less and less.

2 · One parameter site — sample, record, realize

Site model

A site is any PERSONA-controlled knob: neuron-population parameter (Izh a,b,c,d; rate), static-synapse weight, or an STDP hyper-parameter (tau_plus, lambda, alpha, mu±, Wmax).

μs, σs ∈ [bounds]   x̂s = clip(μs + σs·εs)

Single σ: it sets both the explore/exploit scale of the site sample and the biological dispersion of the realized distribution. σ is not moved like a μ-parameter — it runs on its own math — but it is a recorded channel with its own covariations against the output.

Realization — one NEST-consistent interface

  • population site (n neurons): xj = x̂ + σ·ξj, j = 1…n — applied as per-neuron arrays via node.set
  • static synapse site (m synapses): xj = x̂ + σ·ξj — per-synapse draws via the synapse collection
  • STDP hyper-params: scalar sampled value applied to the projection; the weight stays owned by STDP and is only recorded
open With both draws sharing the same σ, the marginal applied value has variance 2σ² (common-mode exploration + differential dispersion). Confirm this is intended, or decide the scaling.

3 · The strategy — two kinds of information

Type 1 — “where to search” (metric)

Channels per site and per noise producer:

μ-channel:   si = Δθi/σi²   (zi = Δθi/σi)
σ-channel:   di = zi² − 1
noise k:   sk = δk/Rk²   (Rk = producer's current value at registration)
Ft = β·Ft−1 + (1−β)·ststT     solve with (Ft + λI)

Persisted across the whole run — stance, swing, everything. Noise is captured here (read-only channels).

Type 2 — “how previous samples impact the current state” (credit)

Distributions know where to search; they don’t know that a sample made 3 steps ago can be what shows up now (SNN delays). So the trace persists:

X̄t = β·X̄t−1 + (1−β)·Δθt      (PERSONA changes only — no STDP/Poisson)
Gt = β·Gt−1 + (1−β)·X̄t·AtT

At step t, X̄t still carries the samples from earlier steps; pairing it with the advantage surfacing now assigns the credit with a decaying weight. F and G are merged into the following — never pruned.

Updates — every dt

gt = Gt·12     Δμt = ημ·(Ft + λI)−1·gt
σ on its own math:   Δlogσi = ησ·clip( di(t)·Āi(t) )   exact form open

σ “does not change with the parameter” — it is not updated through F−1g; but it is inside F, so its current impact makes the μ-step wider or shorter (naturally, through the covariance).
